# MF.FAHIM — Personal Website

A responsive, premium blue-and-white personal portfolio website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. No build tools or paid services are required.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account: https://github.com/
2. Create a **public** repository named `mf-fahim.github.io` (replace `mf-fahim` with your exact GitHub username).
3. Upload `index.html`, `style.css`, `script.js` and this README to the repository's root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. After publishing, your site will be available at `https://YOUR-USERNAME.github.io/`.

## Personalise before publishing
- In `index.html`, replace `YOUR_EMAIL@example.com` with an email address you want visitors to use.
- Add your real GitHub, LinkedIn and other social links when ready.
- Replace the sample project cards with real projects as you complete them.
- The current profile avatar uses initials (MF), so you do not need a photo to launch.

## Notes
- The design uses Google Fonts when internet access is available; system fonts remain as fallback.
- The site is static and does not collect or store visitor data.
